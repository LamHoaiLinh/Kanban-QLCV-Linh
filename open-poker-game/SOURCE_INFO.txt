Open Poker integration for Kanban-QLCV-Linh
Upstream: https://github.com/alexis-labs/open-poker

Kanban customizations:
- Card ranks 2..A enlarged more than 2x for readability
- Sort Hand: Straight (S)
- Sort Hand: Flush (F) with sticky auto-sort
- Play Hand hotkey: Left/Right Ctrl
- Discard hotkey: Left/Right Shift
- Run Info: hand level, Chips x Mult, played count
- Options: SFX, music, new run, save and return
- Current run autosaves/restores; ESC closes panel or returns to Kanban
- Balatro Core Parity: ordered scoring/retriggers/held-card/Joker pass
- Full playing-card modifiers: enhancements, seals, editions
- Deterministic Lucky/Glass rolls + Glass shatter + money effects
- Drag Joker order affects scoring left-to-right
- Balatro Shop parity: 2 shop cards + 2 Booster Packs + Voucher
- Arcana/Celestial/Standard/Buffoon/Spectral packs with Normal/Jumbo/Mega
- Tarot/Spectral target selection + Planet immediate upgrades
- Interest, unused-hand cashout, pack/target autosave
- Balatro L3: Deck/Stake selection + Blind Select + Skip/Tag flow
- Boss Blind effects + cumulative Stake rules + Eternal/Perishable/Rental Jokers
- First deep Joker set: 50 functional Jokers with scaling and retriggers
- Left-click Joker/Consumable info card + Balatro-like Shop composition
- Joker Exact Parity: per-card/on-held/independent timing, Red Seal/Mime/retrigger order
- Exact live counters for Misprint/Runner/Ride the Bus/Green/Ice Cream/Loyalty/Castle
- Boss-debuff-aware Joker/Card interactions + single-roll Glass shatter settlement
- 20 Mythic Jokers above Rare with dedicated rarity visuals and 2% natural roll
