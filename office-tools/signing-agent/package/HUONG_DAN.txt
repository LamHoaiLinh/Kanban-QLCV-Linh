KANBAN SIGNING AGENT 1.0
========================
Mục đích: hỗ trợ tab PDF > Ký số > Ký doanh nghiệp trên KanBan GitHub Pages.

CÀI LẦN ĐẦU
1. Giải nén toàn bộ ZIP.
2. Cắm USB Token và bảo đảm Token Manager/middleware của nhà cung cấp CA đã cài.
3. Double-click CAI_DAT_VA_CHAY.bat.
4. File này tự tạo .venv, cài thư viện và tạo shortcut "KanBan Signing Agent" trên Desktop.
5. Giữ Agent chạy khi ký doanh nghiệp trên KanBan.

LẦN SAU
- Cắm Token.
- Double-click shortcut "KanBan Signing Agent".
- Mở KanBan > Công cụ PDF > Ký số > Ký doanh nghiệp.

BẢO MẬT
- Agent chỉ lắng nghe 127.0.0.1:8765 (máy cục bộ).
- Chỉ chấp nhận origin KanBan của lamhoailinh.github.io và localhost.
- Private key không rời USB Token.
- PIN không được ghi vào file cấu hình.
- PDF không upload ra Internet; KanBan gửi PDF tới localhost trên chính máy.

KHÔNG CẦN
- Không cần tìm viettel-ca_v6.dll.
- Không cần PKCS#11 DLL.
- Không cần Token label / Cert label / Key label.

TÙY CHỌN
- BUILD_ONEFILE.bat: tạo một file EXE sau khi môi trường đã cài xong.

TRÌNH DUYỆT
- Chrome/Edge mới có thể hỏi quyền Local network access khi KanBan kết nối 127.0.0.1; hãy chọn Cho phép.
