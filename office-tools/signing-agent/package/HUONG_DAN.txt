KANBAN SIGNING - THÀNH PHẦN CỦA KANBAN TOOLS
==============================================
File kanban_signing_agent.py là source runtime cho chức năng PDF > Ký số > Ký doanh nghiệp.

CÀI / CẬP NHẬT
- Không cài thư mục này riêng.
- Không còn BAT/EXE cài Signing Agent riêng.
- KanTool.bat duy nhất sẽ tải source này, chuẩn bị thư viện cần thiết và đăng ký chạy cùng Windows.

SỬ DỤNG
1. Chuột phải CÔNG CỤ trong KanBan và bảo đảm KanBan Tools sẵn sàng.
2. Cắm USB Token.
3. Mở CÔNG CỤ > PDF > Ký số > Ký doanh nghiệp.
4. Bấm Kiểm tra kết nối / Đọc chứng thư.

BẢO MẬT
- Runtime chỉ lắng nghe 127.0.0.1:8765.
- Chỉ chấp nhận origin KanBan/localhost được cho phép.
- Private key không rời USB Token.
- PIN không ghi vào file cấu hình.
- PDF không upload ra Internet.
